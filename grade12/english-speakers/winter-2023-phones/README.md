# Winter 2023 Module G workshop

Published from the Grade 12 English-speakers panel. The shared landing page branches to `lesson.html?lang=he` and `lesson.html?lang=en`. Each version has 76 slides with identical English questions and answers. `key.html` uses the same language parameter and can be printed.

The lesson follows Version A. Multiple-choice questions and options are teaching paraphrases; the original paper is linked. Students need the original text alongside the lesson. The Geva fallback includes answers and is labelled accordingly.

The supplied key governs the detailed marking examples. In Q7 it expressly requires scientific knowledge as well as control of youngsters’ minds. High-Q puts the knowledge phrase in parentheses; this difference is disclosed. The workshop reports selected marking examples and does not assign an automatic grade to free text. Original explanations, repair exercises and the model essay are teaching additions.

## Behaviour and checks

Learners attempt, find evidence, compare a model and repair an answer. Answers and phrase selections use local storage without a network submission. Language switches preserve the slide and saved work. Keyboard arrows, a jump selector and boundary-aware vertical swipes navigate. Long slides scroll normally. Phrase choices are synchronized between sentence, paragraph and complete-essay views.

The base essay contains 130 whitespace-delimited words. Current phrase combinations range from 126 to 134. Counts update on changes. Point values sum to 60 for reading and 40 for writing.

Validated both language versions with a DOM runtime: 76 slides, navigation, state persistence, language switching, strategy feedback, word counts, synchronized paraphrases, swipe boundary behaviour and the nine-question extended key. Local asset links and JavaScript syntax checked. No visual browser QA was available in this execution environment.
